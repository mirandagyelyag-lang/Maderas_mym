Maderas M&M — Cubicador móvil Android V5

Esta actualización solo modifica la interfaz del cubicador. No reemplaza el ERP,
no toca .env y no necesita volver a desplegar la función Supabase.

Desde Git Bash, dentro de la carpeta "Finanzas papá":

  unzip -oq ~/Downloads/Cubicador-Movil-Android-V5.zip -d .
  npm run verify:cubicador
  npm run build
  git add src/pages/Cubicador.jsx src/styles/cubicador-enhancements.css src/styles/cubicador-mobile.css scripts/verify-cubicador.mjs
  git commit -m "Mejorar interfaz móvil y recorte del cubicador"
  git push origin main

Cambios:
- Se elimina el bloque confuso "Vista previa de la toma".
- El botón de análisis aparece solo cuando las fotos están completas.
- La captura móvil ocupa mucho menos espacio vertical.
- El editor de foto usa un marco fijo: se mueve la imagen debajo.
- Permite arrastrar, pellizcar y usar una barra de zoom.
- Los controles del editor quedan siempre visibles en la parte inferior.
- Incluye diseño especial para teléfono en vertical y horizontal.
