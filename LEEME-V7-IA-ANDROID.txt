CUBICADOR ANDROID V7 — FOTO E IA AUTOMÁTICA
============================================

Problema confirmado
-------------------
La cámara sí abría, pero algunos Samsung entregaban la foto en HEIC/HEIF.
Chrome no podía abrirla en el editor y mostraba "No se pudo leer la imagen".
En las fotos compatibles, después del recorte todavía había que tocar otro botón
para iniciar la IA, por lo que parecía que no ocurría nada.

Qué corrige
-----------
- Pide JPEG directamente a la cámara trasera de Android.
- Convierte HEIC/HEIF automáticamente si Android o la galería lo entregan igual.
- Inicia la IA automáticamente al aceptar la última fotografía.
- Conserva un botón para reintentar si el proveedor falla.
- Muestra el error real del backend y un código corto de solicitud.
- Incluye también el arreglo de ancho completo y la UI móvil compacta de V6.
- Mantiene el cálculo JAS verificado: 12 rollizos = 3,720 m³.

Instalación desde Git Bash
--------------------------
Abre Git Bash dentro de:
  ~/Desktop/Finanzas papá

Ejecuta, una línea por vez:

  unzip -oq ~/Downloads/Cubicador-Android-IA-Automatica-V7.zip -d .
  npm ci
  npm run verify:cubicador
  npm run build
  git add LEEME-V7-IA-ANDROID.txt index.html package.json package-lock.json scripts/verify-cubicador.mjs src/hooks/use-mobile.jsx src/pages/Cubicador.jsx src/styles/cubicador-mobile.css
  git commit -m "Corregir lectura de fotos Android y análisis automático"
  git push origin main

No hay que volver a desplegar Supabase para esta V7. La función publicada está
activa y la clave GEMINI_API_KEY está configurada.

Prueba en el teléfono
---------------------
1. Espera a que termine el despliegue automático de Vercel.
2. Cierra completamente la app Maderas M&M.
3. Ábrela, toma una foto y toca "Usar este encuadre".
4. Debe aparecer "Analizando…" sin tocar un segundo botón.
5. Si la IA falla, copia el mensaje y el código corto que aparecerán en pantalla.
