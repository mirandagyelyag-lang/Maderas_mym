MADERAS M&M - CUBICADOR CONSENSO 2+1 (VERSIÓN FINAL)

1) Reemplaza src/pages/Cubicador.jsx por el archivo incluido.
2) En Supabase > Edge Functions > cubicar-madera, reemplaza index.ts y pulsa Deploy updates.
3) En Git Bash:
   git add src/pages/Cubicador.jsx
   git commit -m "Mover consenso del cubicador al cliente"
   git push origin main

Funcionamiento:
- Cada Edge Function realiza UNA sola medición.
- El navegador lanza dos Edge Functions separadas en paralelo.
- Si una falla, intenta recuperar la segunda sin botar todo el proceso.
- Si las dos coinciden dentro del 12%, usa el consenso.
- Si no coinciden, ejecuta una tercera llamada como desempate.
- Si ni con tres hay consistencia, bloquea el resultado y pide repetir la foto/sector.

Esto evita mantener una sola Edge Function viva durante 2 o 3 análisis y reduce el riesgo
de shutdown por WallClockTime.
