CUBICADOR ANDROID V9 · LA FOTO DEBE ENTREGAR DATOS
===================================================

ESTE HOTFIX CORRIGE EL ERROR MOSTRADO EN LA CAPTURA:
- Ya no permite pasar desde la fotografía a una fila manual vacía.
- Después de aceptar la última foto, la IA se ejecuta automáticamente.
- El paso “Medidas” solo se abre cuando existen datos detectados.
- Para rollizos deben existir diámetro y cantidad mayores que cero.
- Si la IA responde sin lecturas, la app permanece en Fotografías.
- Las fotos no se pierden y aparece “Reintentar análisis con estas fotos”.
- El botón inferior permanece bloqueado mientras la IA está leyendo.
- La función usa Gemini 3.6 Flash y Gemini 3.5 Flash como respaldo.
- Cliente y servidor informan versión 9.0.0 en el botón “Estado”.

INSTALACIÓN EN GIT BASH
1. Entra a la carpeta:
   cd ~/Desktop/"Finanzas papá"

2. Descomprime el ZIP encima del proyecto:
   unzip -oq ~/Downloads/Cubicador-IA-Datos-Obligatorios-V9.zip -d .

3. Verifica:
   npm ci
   npm run verify:cubicador
   npm run build

4. PUBLICA LA FUNCIÓN DE IA (OBLIGATORIO):
   npx supabase functions deploy cubicar-madera --project-ref vvvxocbvjvsidtikqryo

5. Sube el frontend para que Vercel lo publique:
   git add LEEME-V9-IA-OBLIGATORIA.txt index.html package.json package-lock.json scripts/verify-cubicador.mjs src/hooks/use-mobile.jsx src/lib/imageQuality.js src/pages/Cubicador.jsx src/styles/cubicador-enhancements.css src/styles/cubicador-mobile.css src/styles/cubicador-v8.css supabase/functions/cubicar-madera/index.ts
   git commit -m "Exigir datos de IA después de fotografiar V9"
   git push origin main

6. En Android, espera que Vercel termine, cierra completamente la PWA y ábrela otra vez.
   Toca “Estado” y confirma:
   - cliente V9.0.0;
   - servidor V9.0.0;
   - Servicio de IA: Bien.

COMPORTAMIENTO CORRECTO
Foto -> control de calidad -> análisis IA -> diámetros y cantidades rellenados -> revisión -> cálculo JAS.

Si la foto no es legible:
Foto -> análisis IA -> mensaje claro -> reintentar con las mismas fotos o repetirlas.

Nunca debe aparecer una fila con diámetro 0 como si la fotografía hubiera funcionado.
