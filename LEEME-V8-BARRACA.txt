CUBICADOR DE BARRACA ANDROID V8
================================

QUÉ CAMBIA
- La foto completa es la opción recomendada. Recortar ahora es opcional.
- Antes de enviarla, el teléfono revisa luz, enfoque, contraste y resolución.
- El análisis muestra en qué etapa está; ya no parece quedar pegado sin explicación.
- El botón “Estado” comprueba Internet, sesión, PWA y conexión con la función de IA.
- Cada diámetro leído por IA conserva un nivel de confianza para facilitar la revisión.
- Se mantiene una sola lectura de IA por lote y el cálculo JAS local verificado.

IMPORTANTE
La IA transcribe lo visible, pero una foto no garantiza una cubicación comercial exacta.
Compara siempre los números propuestos con la fotografía y corrige los dudosos antes de guardar.

INSTALACIÓN EN GIT BASH
1. Entra al proyecto:
   cd ~/Desktop/"Finanzas papá"

2. Descomprime este ZIP encima del proyecto:
   unzip -oq ~/Downloads/Cubicador-Barraca-Android-V8.zip -d .

3. Instala y verifica:
   npm ci
   npm run verify:cubicador
   npm run build

4. Publica la función de IA. ESTE PASO ES OBLIGATORIO EN V8:
   npx supabase functions deploy cubicar-madera --project-ref vvvxocbvjvsidtikqryo

5. Guarda y sube los cambios:
   git add LEEME-V8-BARRACA.txt index.html package.json package-lock.json scripts/verify-cubicador.mjs src/hooks/use-mobile.jsx src/lib/imageQuality.js src/pages/Cubicador.jsx src/styles/cubicador-enhancements.css src/styles/cubicador-mobile.css src/styles/cubicador-v8.css supabase/functions/cubicar-madera/index.ts
   git commit -m "Mejorar flujo movil y lectura IA del cubicador V8"
   git push origin main

6. Espera a que Vercel termine. En Android:
   - cierra completamente la app instalada;
   - ábrela otra vez con Internet;
   - si sigue la versión anterior, ciérrala y ábrela una segunda vez;
   - toca “Estado” y confirma que indique cliente V8.0.0 y servidor V8.0.0.

PRUEBA CORTA EN TERRENO
1. Entra a Rollizos > Un rollizo o pocos.
2. Saca una foto cercana, de frente y con el número rojo grande.
3. Usa “Usar foto completa”. Solo usa “Ajustar” si sobra demasiado fondo.
4. Espera las cuatro etapas del análisis.
5. Compara el diámetro y la cantidad con la fotografía.
6. Corrige cualquier lectura dudosa y recién entonces confirma el resultado.

Si algo falla, abre “Estado” y anota el código corto del último análisis. Ese código permite encontrar la falla exacta en los registros de Supabase.
