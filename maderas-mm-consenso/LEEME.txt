MADERAS M&M — CUBICADOR CON CONSENSO DE 3 ANÁLISIS

Incluye:
- src/pages/Cubicador.jsx
- supabase/functions/cubicar-madera/index.ts

QUÉ CAMBIA
1. Cada medición ejecuta 3 análisis independientes.
2. Se calcula un consenso por mediana.
3. Se calcula consistencia real entre los 3 resultados.
4. Si la diferencia máxima supera 12%, el resultado se BLOQUEA.
5. En pila de 4 sectores, se identifica el sector con mayor discrepancia y se pide repetirlo.
6. Si la consistencia es aceptable, se cargan las medidas consensuadas y se muestran los tres conteos internos.
7. Se conservan los fallbacks actuales de Gemini y el flujo de 1 foto / 4 fotos.

PASO 1 — FRONTEND
Reemplaza:
src/pages/Cubicador.jsx

por el archivo incluido.

PASO 2 — EDGE FUNCTION
En Supabase > Edge Functions > cubicar-madera > index.ts
reemplaza todo por:
supabase/functions/cubicar-madera/index.ts

y presiona Deploy updates.

PASO 3 — PUBLICAR FRONTEND
En tu proyecto local:

git add src/pages/Cubicador.jsx
git commit -m "Agregar consenso de 3 analisis al cubicador"
git push origin main

IMPORTANTE
- Cada toque en Analizar hará 3 llamadas de análisis. Consume aproximadamente 3 veces más cuota de Gemini que antes.
- Si la cuota gratuita está muy ajustada, pueden aparecer límites 429 con mayor frecuencia.
- El sistema no garantiza exactitud metrológica. Bloquea resultados inestables, pero las mediciones comerciales deben seguir revisándose visualmente.
